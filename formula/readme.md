# 文本公式识别API服务

将纯文本数学公式转换为LaTeX格式的REST API服务。

## 功能特性

- **文本公式转换**: 将纯文本公式（如 `x = (-b ± sqrt(b^2 - 4ac)) / (2a)`）转换为LaTeX格式
- **公式验证**: 验证LaTeX公式语法的有效性
- **批量转换**: 支持批量处理多个公式
- **公式提取**: 从文本中提取并转换数学公式
- **统一API规范**: 遵循 `/api/v1/{module}/{action}` 格式
- **统一响应格式**: 所有响应遵循 `{data, status_code, msg}` 格式

## 支持的输入格式

- 纯文本数学表达式
- 包含常见数学函数（sqrt, sin, cos, log等）
- 包含上标（^）和下标（_）
- 包含希腊字母（alpha, beta, gamma等）
- 包含特殊符号（±, ≤, ≥, ∞等）
